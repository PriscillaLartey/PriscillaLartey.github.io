### Overview
This portfolio showcases projects that reflect my analytical curiosity and independent explorations, from customer segmentation using K-Means clustering to churn analysis and dashboard development. 

Although results-driven, each project is built to go beyond getting results; I aim to document the reasoning, trade-offs, and context behind the analysis, since I believe that's what separates a useful analysis from a purely technical one. I'm especially drawn to problems at the intersection of customer behavior and applied machine learning.
